# LazyMac 자세한 안내

[README로 돌아가기](../README-ko.md)

## 무엇이 좋은가요

- **백업도 복원도 한 앱에서.** GitHub나 iCloud에 없는 폴더를 클라우드(Google 드라이브, 또는 rclone이 지원하는 70여 클라우드)나 로컬 폴더에 복사하고, 새 맥에서 버튼 하나로 되살려요. 맥에서도 클라우드에서도 아무것도 지우지 않아요.
- **어느 맥에서나.** 계정·폴더·경로가 박혀 있지 않아요. 폴더, 클라우드, LazyMac 저장소를 앱에서 골라요. 폴더 백업은 저장소 없이도 돼요.
- **깨끗한 새 출발.** 지금 맥을 통째로 옮기지 않아요. 쓰는 것만 새로 깔고, 찌꺼기는 두고 가요.
- **일일이 안 봐도 돼요.** 모든 항목을 사용 흔적(마지막으로 쓴 날, 지금 켜져 있는지)으로 미리 ✅ 가져감, ⛔ 두고 감, ❓ 확인 필요로 나눴어요. ❓ 표시된 몇 개만 확인하면 돼요.
- **명령 하나로 깔려요.** 새 맥에서 `bin/setup.sh` 하나가 ✅ 항목만 순서대로 깔고, 비밀값을 되살리고, 백그라운드 작업을 등록해요.
- **맥마다, 쓰임마다 다르게.** 프로필로 "이 맥에는 이것만"을 저장해 두고 골라서 깔아요. 맥 기본 프로필(`pro`·`air`)에 쓰임 프로필(`dev`·`light`·`outside`)을 덧붙이고, 지금 맥과 비교해서 빠진 것과 더 있는 것을 바로 봐요.
- **두 번째 맥도 안전하게.** 맥마다 훑은 목록을 따로 두고, 모든 맥에서 사라진 것만 목록에서 빼요. 에어처럼 가끔 쓰는 맥은 열 때만 훑거나, 원하면 자동 백업 주기를 정해 둘 수 있어요.
- **맥 구조가 한눈에 보여요.** 앱, 명령줄 도구, 뒤에서 도는 것, 설정, 비밀값, 다른 저장소에 있는 것으로 나누고 같은 성격끼리 묶었어요.

## 앱 화면 안내

LazyMac은 양쪽으로 써요. **백업**은 지금 맥을 지키고, **복원**은 다음 맥에서 되살려요. 왼쪽 사이드바에 둘 다 있어요.

- **백업 → 한눈에**: 복사하는 곳, 폴더 수, 마지막 백업과 비교, 일정과 마지막 예약 실행 결과, 그리고 LazyMac 저장소가 있으면 이 맥의 앱과 설정 목록(*이 맥 훑기*).
- **백업 → 폴더**: rclone 설치와 클라우드 연결(Google 드라이브는 앱에서 바로, 다른 클라우드는 `rclone config`로), 폴더 넣고 빼기, 추가로 뺄 패턴, 그리고 *지금 백업*과 *비교*(복사 없이 비교만).
- **백업 → 일정**: 매시간, 몇 시간마다, 매일, 매주. 앱을 닫아도 뒤에서 돌아요.
- **복원 → 폴더**: *백업된 폴더 찾기*로 찾고, 원하는 폴더를 골라 원래 있던 곳이나 다른 폴더에 되살려요. 맥에 이미 있는 파일은 건드리지 않아요. '백업보다 오래된 파일은 바꾸기'를 켜면 오래된 파일만 바꿔요.
- **복원 → 앱과 설정**: LazyMac 목록에서 고른 것을 네 단계로 설치해요(아래).

앱은 영어와 한국어를 지원하고 시스템 언어를 따라가요(시스템 설정 → 일반 → 언어 및 지역, 앱별 설정도 가능해요). *보기 → 글자 크게*(`⌘+`)로 모든 글자를 두 배까지 키우고, `⌘0`으로 원래 크기로 돌아와요.

**받기.** [Releases](https://github.com/floweredao/LazyMac/releases/latest)에서 `LazyMac-<버전>.zip`을 받아 풀고, `LazyMac.app`을 응용 프로그램 폴더로 옮겨요. 처음 열면 막히니 시스템 설정 → 개인정보 보호 및 보안 → 맨 아래 "그래도 열기"를 눌러요(개인 서명이라 애플 공증이 없어요). 정해진 시각에 도는 백업이 폴더를 읽을 수 있게, LazyMac에 '전체 디스크 접근'을 허용해 주세요(백업 → 일정에 버튼이 있어요).

## 새 맥 세팅

### 앱으로 (가져갈 것을 직접 고르고 싶을 때)

1. 맥 첫 설정을 끝내고 App Store에 로그인해요.
2. 위처럼 앱을 받고 *복원 → 폴더*에서 폴더부터 되살려요.
3. *복원 → 앱과 설정*을 열면 네 단계로 안내해요.
   - **준비**: Homebrew, GitHub CLI 설치, GitHub 로그인(확인 코드 복사 버튼 있음), LazyMac 저장소 받기(`owner/이름`, GitHub 계정으로 미리 채워짐)를 버튼 하나씩으로 해요. 저장소가 없어도 폴더 백업은 돼요.
   - **고르기**: 이 맥의 프로필(`machines.tsv`)대로 미리 체크돼 있어요. 왼쪽 위 *프로필* 메뉴에서 다른 맥 프로필을 고르거나 쓰임 프로필을 덧붙이고, 고른 것을 *프로필로 저장*하거나 *이 맥과 비교*할 수 있어요. 원치 않는 항목을 빼거나, "두고 가기로 한 것도 보기"를 켜서 ⛔ 항목을 더할 수 있어요. 설정 파일·비밀값·저장소·확인 단계도 켜고 끌 수 있어요.
   - **확인**: 어떤 단계가 몇 개를 설치하는지 보여 줘요.
   - **설치**: 단계별 진행과 출력이 보여요. 맥 암호나 비밀값 묶음 암호를 물으면 아래 입력칸이 주황색으로 바뀌어요. 문제가 생긴 단계만 다시 돌릴 수 있어요.

앱은 고른 항목으로 `setup/`과 같은 형식의 목록을 `~/Library/Application Support/lazymac/selection/`에 만들고 `LAZYMAC_SETUP_DIR`로 `bin/setup.sh`를 돌려요. 설치 방식은 터미널과 똑같아요.

**앱 출처.** 앱을 어디서 받는지 확인하거나 고치려면 왼쪽 아래 *앱 출처 관리…*(또는 Window → 앱 출처)를 눌러요. GitHub 릴리즈, 다운로드 페이지, 직접 빌드로 받는 앱이 모두 나오고, 항목마다 저장소나 주소, 최신 릴리즈와 설치할 파일, 설치된 버전, 업데이트 표시가 보여요. *GitHub에서 찾기*는 설치된 앱의 업데이트 피드 주소를 포함해 후보 저장소를 보여 주고, *자동 설치로 바꾸기*는 다운로드 페이지를 GitHub 릴리즈로 바꿔요. 창을 열면 먼저 GitHub에서 최신본을 받고, *저장하고 동기화*를 누르면 `catalog.tsv`를 고치고 `setup/`과 README를 다시 만든 뒤 커밋·푸시까지 해서 다음 설치부터 바로 적용돼요. 릴리즈 안에서 특정 파일만 고르려면 `owner/repo#패턴`(예: `#*-arm64.dmg`)처럼 적어요.

### 프로필과 여러 맥

- **프로필** (`profiles/<이름>.txt`): 맥 기본 프로필은 `from keep`(✅ 전부)에서 시작해 `- group app/vm`, `+ cli/rustup` 같은 줄로 빼고 더해요. 쓰임 프로필은 `from` 줄 없이 이런 줄만 있어서 기본 프로필 위에 덧붙여요. 예시 프로필: `pro`, `air`(주 맥만 돌리는 작업 제외), `dev`, `light`(큰 개발 도구 제외), `outside`(백그라운드 작업·원격 제어 제외).
- **맥 연결** (`machines.tsv`): 맥 이름마다 역할(`main`은 주 맥)과 프로필을 적어요. 여기 없는 맥은 보조 맥(`extra`)이고 `pro` 프로필로 시작해요.
- **비교**: `bun bin/catalog.ts compare air,light`(앱에서는 *이 맥과 비교*)가 이 맥에서 빠진 것(설치하면 들어옴), 더 있는 것(보여 주기만 하고 지우지 않음), 같은 것을 나눠 보여 줘요.
- **맥마다 훑기**: 훑은 결과는 `inventory/<맥 이름>/`에 맥마다 따로 있어요. 매일 정리(`prune`)는 모든 맥에서 사라진 항목만 목록에서 빼요.
- **보조 맥(예: 에어)**: 기본적으로 백그라운드 작업이 없어요. 앱의 *이 맥 훑기*(또는 `bin/scan.sh`)를 누를 때만 이 맥 목록을 올려요. 정기 백업을 원하면 *백업 → 일정*(또는 LazyMac → 설정, `⌘,`)에서 *자동으로 백업하기*를 켜고 주기(매시간·몇 시간마다·매일·매주와 시각·요일)를 고른 뒤 *적용*을 눌러요. 보조 맥은 자기 목록만 올리고 올리기 전에 최신본을 받아서, 주 맥과 부딪치지 않아요. `storage.conf`에서 `files on`을 켜 두고 *백업 → 폴더*에 폴더를 정해 두면 돌 때마다 폴더도 백업해요.
- **주 맥(예: 프로)**: 매일 04:00 작업(훑기, 목록 정리, 스냅샷, 히스토리 페이지, 그리고 켜 둔 경우 폴더 클라우드 백업)을 해요. 이 시각도 같은 화면에서 바꿀 수 있어요.

### 터미널로 (✅ 전부 그대로)

1. 맥 첫 설정을 끝내고 App Store에 로그인해요.
2. 터미널을 열고 아래를 붙여 넣어요.

   ```sh
   /bin/bash -c "$(curl -fsSL https://raw.githubusercontent.com/Homebrew/install/HEAD/install.sh)"
   eval "$(/opt/homebrew/bin/brew shellenv)" && brew install gh && gh auth login
   gh repo clone alex/lazymac ~/Documents/lazymac
   ~/Documents/lazymac/bin/setup.sh
   ```

3. 남는 건 직접 해야 하는 단계뿐이에요: 앱이 물어보는 권한 허용, 앱 로그인, 자체 복원 안내가 있는 도구 복원.

`setup.sh`가 하는 일(순서대로):

- Homebrew·App Store 앱과 글꼴 설치
- Node.js, bun, 파이썬과 그 전역 도구들 설치
- 자체 설치 스크립트가 있는 도구 설치
- GitHub 릴리즈가 있는 앱은 최신 릴리즈에서 이 맥에 맞는 `.dmg`·`.zip`을 받아 설치
- 터미널·Git·tmux·npm·SSH 설정과 Dock 설정 복사
- 비밀값·로그인 파일·개인 작업 파일 되살리기(묶음 암호를 한 번 물어봐요)
- `setup.sh`에 적힌 보조 저장소 받아 설치
- ✅ 백그라운드 작업 등록(필요한 프로그램이 아직 없으면 기다렸다가, 다시 돌리면 등록)
- Homebrew에도 GitHub 릴리즈에도 없는 앱의 내려받기 페이지 열기
- 직접 깔아야 하는 앱 안내 및 아직 빠진 항목 확인

프로필대로 깔려면 `bin/setup.sh --profile air,light`처럼 써요. 단계를 적지 않으면 프로필이 `skip`으로 뺀 단계만 빼고 다 돌려요.

여러 번 돌려도 괜찮아요. 이미 된 건 건너뛰고, 아무것도 지우지 않아요. 옛 맥을 떠나기 전에 할 일과 단계별 자세한 내용은 [복원 안내](restore-ko.md)에 있어요.

### 앱 고치고 릴리즈하기

앱 코드는 `app/`(SwiftUI, Swift Package)에 있어요. 항목은 앱 안에 박혀 있지 않고 실행할 때 `catalog.tsv`를 읽어서, 카탈로그만 바뀔 땐 릴리즈할 필요가 없어요. 앱 자체를 고쳤을 때만 아래를 실행해요.

```sh
tests/app-setup-files.sh            # 앱이 만드는 목록이 setup/·catalog.ts profile과 같은지
tests/app-schedule.sh               # 자동 백업 일정이 LaunchAgent에 그대로 들어가는지 (임시 폴더에서)
# app/VERSION 올리기 (화면·동작 추가 1.x.0, 버그 수정 1.0.x)
app/build.sh                        # app/build/LazyMac-<버전>.zip
gh release create app-v$(cat app/VERSION) app/build/LazyMac-$(cat app/VERSION).zip -R floweredao/LazyMac --title "LazyMac App $(cat app/VERSION)"
```
